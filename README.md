# Chrome-Dino

Historical Assembly learning project from 2020: a clone of the Chrome dinosaur game, exploring low-level game logic and screen output.

## Repository contents

- `Project.asm`: Assembly source.
- `Project.COM`: original compiled program.
- `Output (1).png` and `Output (2).png`: original screenshots.

The source and screenshots are preserved as learning work. The original assembler and execution environment have not been revalidated as part of this documentation update.
